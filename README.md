# EV Charging Demand Project

This starter project includes a small Python analysis workflow for EV charging demand data.

## Files
- app.py: loads the sample CSV and prints a summary of charging demand.
- EV_Charging_Demand_Final.csv: sample demand data for analysis.
- notebooks/EV_Charging_Analysis.ipynb: exploratory notebook for further analysis.

## Run the script
```bash
python app.py
```

## Install dependencies
```bash
pip install -r requirements.txt
```
